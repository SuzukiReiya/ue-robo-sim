# Windows / UE 5.6 初回検証

利用者側でUEの起動・旋回を確認済みです。今回の修正後のUEビルド・実機操作については未実施のため、以下の項目で検証してください。

1. `BuildAndRun.ps1 -BuildOnly`でUHT・C++・リンク・マップ生成が成功すること。`Saved/GeneratedTextures/`のPBR画像9枚と`/Game/Generated`の`*_PBRv2`材質・画像アセットが生成され、`map.log`に`ROBOT_SIM_MAP_READY: PBR v2`が出ること。特に`SimVideoPipeline`のUCLASSと`CreateMap.py`の材質生成・画像インポートのエラーがないこと。
2. 起動して**近距離でも**プラダンの細かな筋、床の擦れ、陰影・表面の粗さが見え、赤い移動対象が背景に埋もれず、柵の向こうに屋内ホールの柱・天井・外周壁・備品が見えること。模様が均一すぎないか、赤色対象を背景と区別できるか確認する。暗くて見えない場合は`CreateMap.py`の生成・材質・CaptureSceneを切り分ける。
3. 遅延0・手動モード（キー1）でW/Sの前後、A/Dの左右平行移動、マウス左右の旋回、Spaceの即時停止を確認する。F1の表示で手動／適用前後入力、速度の正負、XY座標の変化を照合する。障害物に接していない場合は「移動遮断=いいえ」であることを確認する。
4. 壁に向けて前進した場合だけ「移動遮断=はい」となり、壁をすり抜けないこと。後退して離脱できること。床面との接触だけでは移動遮断されないこと。
5. VideoDelayMs=1000で映像のみ遅れ、CommandDelayMs=1000で指令のみ遅れることを別々に確認する。
6. F1で表示を有効にして、画像経過時間が設定遅延＋撮影周期程度であることを確認する。
7. ExportFramesを有効にし、SensorのPNGとlatest.jsonが更新されること。
8. 追尾サンプルを起動し、自動モードで赤い対象の方向へ旋回すること。
9. 共有モードで操縦者と外部指令が設定比率で合成されること。
10. 外部サンプルを止め、自動モードは250ms以内のシミュレーション時間で停止指令へ切り替わること。機体は時定数で減速する。
11. truth.csvとsettings.jsonが保存され、別起動で上書きされないこと。
12. 固定seedの複数試行、欠落率1、最大遅延、低FPS条件でもキューが際限なく増えないこと。
13. SIM_OVERRUNが出た試行を実時間性能の評価対象から除外する。

## 一時停止・操作設定の追加確認

1. Escを押すとメニューを開き、機体・対象・映像・シミュレーション時計が止まること。画面内のボタンやコンボボックスがマウス操作できること。
2. Escを再度押すか「保存せず再開」で閉じ、操作入力が復帰すること。押しっぱなしのEscでメニューが再表示されないこと。
3. W/S/A/Dや左右平行移動・旋回を異なるキーやマウス方向に割り当て、「保存して再開」で指令に反映されること。左右クリックからも射撃を割り当てられること。
4. MouseRightを右旋回、MouseLeftを左旋回にした場合、カーソル非表示のゲーム画面で相対移動量に応じて旋回し、止めれば旋回入力がゼロになること。
5. 同一キーを複数操作に設定すると保存ボタンが無効になり、既存設定が失われないこと。「初期値に戻す」は保存するまで永続化しないこと。
6. 再起動後も`Saved/Config/InputBindings.json`の割り当てを復元すること。不正なJSONを読み込んだ場合は初期値へ戻ること。
7. 一時停止中にSpace・移動・射撃・数字キーを操作しても、機体や制御モードを変えないこと。再開後に古いUDPやキー入力がまとめて適用されないこと。
8. 初期割り当ての左クリックで試験用レイキャストが発生し、F1の射撃回数と`SIM_FIRE`ログが増えること。停止中と自動モード中に手動射撃が発生しないこと。
9. 画面の「終了」ボタンでUEを正常に終了できること。従来のEsc終了操作は廃止されていること。

UE 5.6のWindows実機でのUI・マウスキャプチャ・射撃描画の確認は未実施です。GitHub ActionsではUEに依存しない操作割り当て・制御キューを検証します。

実機校正前の移動モデル、仮の見た目、色抽出追尾の成功を、そのまま実機性能の根拠にしないこと。

## 追加パラメータの確認

1. プルダウンを開き、選択中と選択候補が暗い背景でも明確に読めること。
2. 初期値ではA/Dでカメラの向きを変えずに横移動し、マウス左右で旋回すること。W/Sを同時に押して斜め移動できること。
3. 全操作を「なし」にして保存できること。複数操作に同じキーを割り当てたときだけ保存不可となること。
4. マウス左右・上下感度を変えると同じピクセル移動で旋回／移動強度が変化すること。マウスボタンの操作強度は移動／旋回へ割り当てた場合だけ作用し、射撃回数は変えないこと。
5. 機体揺れ0と8度を比較し、加速・減速・旋回でカメラ姿勢と射線が異なること。射撃ブレ0と8度を比較し、射線分散と発射後のカメラ反動が異なること。
6. タイヤ滑り0と1を比較し、旋回しながら走行する際の横滑り距離が変わること。機体方向と位置の変化をF1で確認すること。
7. 指令遅延・映像遅延をそれぞれ0～1000msで変え、片方だけの変更が他方を変えないこと。射撃要求には指令遅延だけが適用されること。
8. 表示FPSを1と60に変更し、映像更新頻度が変わること。最大60FPSと映像遅延1000msを組み合わせてもフレームの上書きが起きないこと。
9. Escから設定を保存し、再起動後に項目が復元されること。旧バージョンの入力設定ファイルを読み込んだ場合の移行動作を確認すること。
10. `Saved/Experiments/<実行ID>/parameter_changes.csv`に変更時刻と値が追記されること。真値CSVに横移動と姿勢情報が追記されること。

## ATTRACTSヒットパネルと旋回慣性（公式v1.0・35～36ページ）

1. **旋回慣性**：Esc画面で0msと450msを設定し、同じ長さの旋回入力を与えた後に離す。450msでは角速度が残り、機体の旋回が徐々に止まること。Spaceでの非常停止は即時にゼロになること。
2. **インポート**：初回の`.local/logs/map.log`で`ROBOT_SIM_PANEL_MESH_READY`を確認。代替表示の場合は`ROBOT_SIM_PANEL_MESH_FALLBACK`とOBJインポータの状態を確認。OBJのバウンディングボックスが約9×9×1.9cmであること。
3. **四枚配置**：前・右・後・左の4枚が対向し、パネル面は地表面から75°になること。機体が左右に動いてもパネル同士の相対位置・姿勢が変わらないこと。
4. **高さ**：Esc画面の低6cm・標準9cm・高12cm・上限付近14.5cm・段違い（前後12/左右6）を選び、中心高さがそれぞれ一致すること。再起動後も設定が復元されること。
5. **体積**：初期寸法30×30×30cmを超えないこと、パネル下端が床より上であること、可視・射撃判定面が機体本体に埋もれていないこと。特に最も低いパターンと上限付近のパターンを確認。
6. **前方非遮蔽**：パネル面から勾配60°で押し出した領域を、左右の隣接パネルや車体で塞がないことを多方向のレイで検証。**現在この空間検査の自動化は未実装**。
7. **射撃**：各方位から射撃し、`SIM_FIRE`の`パネル被弾=はい`とF1パネル命中累計が増えること。発射しただけでは増えず、通常の壁に命中した場合も加算しないこと。
8. **視線**：自機の低いカメラから高さ6～14.5cmのパネルが画面に収まり、追跡対象が近距離／遠距離の両方で識別できること。
9. **実験**：`truth.csv`へパネル配置パターンと累計命中数が追記され、`settings.json`・`parameter_changes.csv`へ旋回慣性と高さ設定が記録されること。

ルール原文：『ATTRACTS ルールブック v1.0』III-2.1（34ページ）、III-3.3（35～36ページ）。可視化用メッシュは提供STEPの簡略化であり、図面・車検の公認代替ではありません。

## 基本4設定（ゲーム方式の感度・msラグ）

1. Esc設定画面の**先頭**に「移動感度（倍）」「旋回感度（倍）」「操作ラグ（ms）」「映像ラグ（ms）」の4項目が表示されること。各項目にスライダーと数値欄があり、相互に同期すること。
2. 移動感度を0.1倍、1.0倍、20.0倍へ変更し、同じW入力で定常速度が15／150／3000cm/sに近づくこと。横移動A/Dでも同じ倍率が適用されること。
3. 旋回感度を0.1倍、1.0倍、20.0倍へ変更し、同じマウス操作で旋回角速度の大きさが変わること。既存の旋回慣性の時定数は変更されないこと。
4. 操作ラグを0、125、750msに変更し、操縦操作と射撃への反映が独立して遅れること。映像ラグを0、150、750msに変更し、映像だけが遅れること。
5. 数値欄でms単位の整数値を直接入力し、Enterまたは他の欄へ移動することで反映されること。感度欄は0.1倍刻みで入力でき、0.1～20.0倍で制限されること。
6. 保存→終了→`BuildAndRun.ps1`（遅延引数なし）で再起動し、4設定が復元されること。コマンドラインに`-CommandDelayMs 0 -VideoDelayMs 0`を指定した場合はその起動だけ0msになること。
7. `Saved/Config/InputBindings.json`の`version`が4、`move_sensitivity`・`turn_sensitivity`が含まれ、実験の`settings.json`にも同条件が記録されること。
8. 旧v3の`mouse_horizontal`と`mouse_vertical`のみ含む設定ファイルを読み込み、倍率へ移行されること。新v4の倍率項目がある場合には旧値で上書きされないこと。
9. 「初期値に戻す」で感度1.0倍・ラグ100msへ戻り、保存せず再開した場合は変更が反映されないこと。

Windows UE5.6のUMG画面・テキスト入力・マウスキャプチャの実際の動作はGitHub Actionsで確認できないため、実機確認が必要。
