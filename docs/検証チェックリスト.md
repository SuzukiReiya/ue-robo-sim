# Windows / UE 5.6 初回検証

現在の作成環境にはUE本体・Windows・PowerShellがないため、以下は未実施です。

1. `BuildAndRun.ps1 -BuildOnly`でUHT・C++・リンク・マップ生成が成功すること。
2. 起動して床、壁、障害物、赤い移動対象が見えること。黒画面の場合は材質・露出・HUD・CaptureSceneを切り分ける。
3. 遅延0でW/Sの前後、A/Dの旋回、Spaceの即時停止を確認する。
4. VideoDelayMs=1000で映像のみ遅れ、CommandDelayMs=1000で指令のみ遅れることを別々に確認する。
5. F1で表示を有効にして、画像経過時間が設定遅延＋撮影周期程度であることを確認する。
6. ExportFramesを有効にし、SensorのPNGとlatest.jsonが更新されること。
7. 追尾サンプルを起動し、自動モードで赤い対象の方向へ旋回すること。
8. 共有モードで操縦者と外部指令が設定比率で合成されること。
9. 外部サンプルを止め、自動モードは250ms以内のシミュレーション時間で停止指令へ切り替わること。機体は時定数で減速する。
10. truth.csvとsettings.jsonが保存され、別起動で上書きされないこと。
11. 固定seedの複数試行、欠落率1、最大遅延、低FPS条件でもキューが際限なく増えないこと。
12. SIM_OVERRUNが出た試行を実時間性能の評価対象から除外する。

実機校正前の移動モデル、仮の見た目、色抽出追尾の成功を、そのまま実機性能の根拠にしないこと。
