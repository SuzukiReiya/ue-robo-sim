# シミュレータ構成と拡張方針

## 原則

- **入力機器**・**操作解釈**・**制御裁定**・**機体プラント**・**映像取得/伝送**・**操縦者表示**を分離する。
- 共有／自動制御には対象真値を渡さない。真値は評価ログのみ。
- 映像遅延とコマンド遅延は別々に加える。カメラから機体内の制御器へ渡す画像に操縦者向け映像遅延を適用しない。
- 物理・映像の実験を比較する場合、テクスチャ・乱数seed・照明条件を固定する。

## データの流れ

```text
UE入力 → FSimKeyboardInput::Read() → OperatorButtons
                                      ↓
                   RobotSim::CommandRouter::submitButtons()
                         ├ toCommand() : キー状態 → Command
                         ├ DelayQueue : 指令遅延
ローカルUDP外部制御 → submitExternal() ───┤
                         └ resolve() : 手動/共有/自動 + タイムアウト
                                      ↓ Command(throttle, turn)
                             FSimVehicle::Advance()
                                  120Hz XY運動
                                      ↓
               UEシーン ← FSimEnvironment::Build()
                                      ↓
                URobotVideoPipeline（640×360 / 20fps）
                         ├ 撮影→PNG出力（任意・未遅延）
                         └ 映像キュー→表示遅延
                                      ↓
                                ASimHUD表示

別系統: 機体位置・速度・コマンド真値 → truth.csv
```

## 変更する場所

| 修正目的 | 主なファイル | 影響を局所化する対象 |
|---|---|---|
| キー配置・操縦器 | `SimKeyboardInput.*` | 入力の取得 |
| キーを前後進・旋回へ変換 | `SimControl.h::toCommand` | 入力正規化 |
| 共有制御・自動照準・指令選択 | `SimControl.h::CommandRouter` | 制御裁定 |
| 機体の速度・慣性・衝突 | `SimVehicle.h`, `SimCore.h::Drive` | 機体モデル |
| カメラ解像度・映像遅延・出力 | `SimVideoPipeline.*` | 観測経路 |
| 描画UI | `SimGameMode.cpp::ASimHUD` | 操縦者表示 |
| 物体・施設配置 | `SimEnvironment.*` | 幾何と見た目 |
| 模様の生成 | `Scripts/GenerateTextures.py` | 生成画像 |
| 材質アセット構築 | `Scripts/CreateMap.py` | エディタ生成 |

## モードと安全性

- `1` 手動：遅延した操縦指令のみ。
- `2` 共有：有効な外部指令があれば重み付き合成、なければ手動。
- `3` 自動：有効な外部指令のみ。期限切れならゼロ指令。
- 手動・外部の指令有効期限は各250ms。モード切替で手動遅延キューを消去。
- Space非常停止は遅延を適用しない例外で、車両の速度も即時ゼロとする。
- 現在の自動制御はUDP入力を受けるだけで、UE内に画像認識モデルは搭載していない。

## テクスチャと性能評価に関する注意

画像は256×256の3種類（板・コンクリート・床）を固定seedで生成してタイル配置する。実機の撮像ノイズ、被写界深度、ローリングシャッター、反射、照明変動は含まない。既存の生成済み`/Game/Generated`アセットがある場合、同名アセットは再利用する。将来テクスチャ生成ロジックを変更した際は、変更対象の`T_*`と`M_*`をアセット更新すること。

屋内形状は現状仮設定で、競技規定寸法を意味しない。現時点の物理モデルは平面走行で、車輪接触や旋回時の衝突Sweepは未実装。
