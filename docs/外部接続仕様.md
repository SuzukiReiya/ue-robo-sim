# 外部接続仕様 v0

## 指令

UDP、宛先127.0.0.1:9876、UTF-8 JSON、1データグラム2047バイト以内。

```json
{"seq":1730000000000,"throttle":0.0,"turn":0.5}
```

- seq: シミュレータ起動中に単調増加する有限数。古い番号は破棄。サンプルはミリ秒epochを使用。
- throttle: -1〜1。正が前進。
- turn: -1〜1。正が右旋回。
- 非有限値や必須フィールド欠落は破棄。指令値は範囲内に制限。
- 受信処理はゲームスレッドで最大64パケット／フレーム。
- 外部指令は機体内制御を想定し、手動指令の通信遅延キューを通さない。
- 単一クライアントを想定。複数送信者の調停や認証はない。localhost以外にはbindしない。

## カメラ

`-ExportFrames`指定時に`Saved/Sensor/latest.json`を公開。

```json
{"id":12,"capture_sim_s":0.6,"image":"frame_0.png","width":640,"height":360}
```

画像はPNG、機体カメラのRGB画像。時刻はセンサ撮影を指示したシミュレーション時刻で、壁時計やGPU完了時刻ではない。
画像をtmpへ保存して置換し、最後にマニフェストを置換する。読取側はマニフェスト→画像→マニフェストの順に読み、前後が異なれば棄却する。画像は2枚で循環するため長時間保持しない。
UEを再起動するとidとシミュレーション時刻はリセットされる。初回撮影までは前回実行のファイルが残る場合があるため、制御器は更新の有無も監視する。

## 時間・座標

UE側の位置はcm、Yawは度、+Xが初期前方、+Yが右、+Zが上。内部の運動更新は120Hz。
操縦者向けカメラ映像は別の遅延キューを通る。制御器へ正解座標は渡さない。
評価用truth.csvは実験フォルダへ分離。現在の初期版では独立したIMU／エンコーダ出力はまだ実装していない。
